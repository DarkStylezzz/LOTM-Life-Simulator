# Trello board images

Images shown inside the cards of the BitBeyonder Trello board
(https://trello.com/b/d4azTm4x/bitbeyonder). Trello loads them from this
repository, so **don't move or delete this folder** or the cards lose their pictures.

- `pathways/`: emblems of all 22 pathways (14 from the TikTok promo art, 8 downloaded from the game's Roblox assets), resized.
- `passes/`: the game pass icons, downloaded from the live Roblox game (2026-11-02).
- `badges/`: the 15 badge icons, downloaded from the live Roblox game (2026-11-02).
- `art/`: game icon and thumbnail, city backdrops, combat and equipment art, product icons.
